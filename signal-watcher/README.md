[Api Docs](https://docs.rs/signal-watcher/latest/)

> A library that waits for the signal that asks a process to stop. It turns the interrupt and the terminate signal of the operating system into a call of a handler, so a server can shut down in an orderly way.

## Installation

To use this crate, you can run cmd:

```shell
cargo add signal-watcher
```
