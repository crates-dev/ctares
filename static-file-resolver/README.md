[Api Docs](https://docs.rs/static-file-resolver/latest/)

> A library that resolves the file a request asks for under a root directory. It refuses a path that climbs out of the root, so a request cannot reach a file the root does not hold.

## Installation

To use this crate, you can run cmd:

```shell
cargo add static-file-resolver
```
