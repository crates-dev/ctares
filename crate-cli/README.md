# crate-cli

A command-line tool for managing Cargo package lifecycles: version bump, workspace dependency sync, members-ordered publish and code formatting.

## Install

```sh
cargo install crate-cli
```

## Usage

```sh
crate bump --minor
crate sync
crate publish
crate fmt
crate --help
```
