[Api Docs](https://docs.rs/encoding-negotiator/latest/)

> A library that negotiates the content encoding of an HTTP answer. It picks the encoding a client asked for out of the encodings that are offered, and tells whether a body of a content type is worth compressing.

## Installation

To use this crate, you can run cmd:

```shell
cargo add encoding-negotiator
```
