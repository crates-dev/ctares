[Api Docs](https://docs.rs/cors-policy/latest/)

> A library that decides the cross origin policy of an HTTP answer. It tells whether an origin is allowed and builds the cross origin headers of the answer.

## Installation

To use this crate, you can run cmd:

```shell
cargo add cors-policy
```
